Part A: The Power of Diffusion Models!

Part A Overview

In this project, we explore the power of diffusion models for image generation and manipulation. Diffusion models work by gradually adding noise to images (forward process) and learning to reverse this process (denoising). We implement sampling loops from scratch, use pre-trained DeepFloyd IF diffusion models, and create optical illusions including visual anagrams and hybrid images. The project demonstrates how these models can be used for tasks beyond simple generation, including inpainting, image-to-image translation, and creating images that change appearance under different transformations.

Part 1.1: Implementing the Forward Process

The forward process adds noise to a clean image according to the diffusion equation:

$$q(x_t|x_0) = \mathcal{N}(x_t; \sqrt{\bar{\alpha}_t}x_0, (1-\bar{\alpha}_t)I)$$

which is equivalent to:

$$x_t = \sqrt{\bar{\alpha}_t}x_0 + \sqrt{1-\bar{\alpha}_t}\epsilon \text{ where } \epsilon \sim \mathcal{N}(0,1)$$

Implementation Details

The forward process takes a clean image $x_0$ and adds Gaussian noise scaled by $\bar{\alpha}_t$ at timestep $t$. As $t$ increases, more noise is added. The alphas_cumprod array contains $\bar{\alpha}_t$ values for all timesteps $t \in [0, 999]$.

  • For $t=0$: $\bar{\alpha}_0 \approx 1$ (clean image)
  • For large $t$: $\bar{\alpha}_t \approx 0$ (pure noise)

Part 1.4: Iterative Denoising

Diffusion models are designed to denoise iteratively. Instead of removing all noise in one step, we gradually remove noise over multiple steps, which significantly improves quality.

Iterative Denoising Formula

$$x_{t'} = \frac{\sqrt{\bar{\alpha}_{t'}}\beta_t}{1-\bar{\alpha}_t}x_0 + \frac{\sqrt{\alpha_t}(1-\bar{\alpha}_{t'})}{1-\bar{\alpha}_t}x_t + v_\sigma$$

where:

  • $x_t$ is the current noisy image at timestep $t$
  • $x_{t'}$ is the less noisy image at timestep $t' < t$
  • $x_0$ is our estimate of the clean image from one-step denoising
  • $\alpha_t = \bar{\alpha}_t / \bar{\alpha}_{t'}$
  • $\beta_t = 1 - \alpha_t$
  • $v_\sigma$ is random noise variance

Strided Timesteps

Instead of running 1000 denoising steps, we use a stride to skip steps:

  • Start: t = 990
  • Stride: 30
  • End: t = 0
  • Timesteps: [990, 960, 930, ..., 30, 0]

Starting index i_start = 10 corresponds to timestep t = 690

Part 1.6: Classifier-Free Guidance (CFG)

Classifier-Free Guidance significantly improves generation quality by computing both conditional and unconditional noise estimates and extrapolating in the conditional direction.

CFG Formula

$$\epsilon = \epsilon_u + \gamma(\epsilon_c - \epsilon_u)$$

where:

  • $\epsilon_c$ = conditional noise estimate (with text prompt)
  • $\epsilon_u$ = unconditional noise estimate (empty prompt "")
  • $\gamma$ = guidance scale (controls strength)

For $\gamma = 1$: standard conditional generation

For $\gamma > 1$: enhanced quality with reduced diversity

Implementation Details

CFG Scale: $\gamma = 7$

The UNet is called twice per denoising step:

  1. Once with the text prompt for $\epsilon_c$
  2. Once with empty prompt "" for $\epsilon_u$

The final noise estimate is the weighted combination according to the CFG formula.

Part 1.7.2: Inpainting

Inpainting allows us to fill in masked regions of an image while preserving the unmasked areas. We achieve this by running the denoising loop but replacing unmasked regions at each step.

Inpainting Algorithm

At each denoising step, after obtaining $x_{t'}$, we replace unmasked regions:

$$x_{t'} \leftarrow m \cdot x_{t'} + (1-m) \cdot \text{forward}(x_{\text{orig}}, t')$$

where:

  • $m$ is the binary mask (1 = edit region, 0 = preserve)
  • $x_{\text{orig}}$ is the original image
  • forward() adds the appropriate amount of noise for timestep $t'$

Part 1.8: Visual Anagrams

Visual anagrams are optical illusions created by combining noise estimates from two different prompts - one for the normal orientation and one for the flipped orientation. The result is an image that appears as one thing normally, and another thing when flipped.

Visual Anagram Algorithm

At each denoising step:

  1. $\epsilon_1 = \text{CFG of UNet}(x_t, t, p_1)$ - denoise with prompt 1
  2. $\epsilon_2 = \text{flip}(\text{CFG of UNet}(\text{flip}(x_t), t, p_2))$ - denoise flipped image with prompt 2
  3. $\epsilon = (\epsilon_1 + \epsilon_2) / 2$ - average the noise estimates
  4. Use $\epsilon$ for the denoising step

The flip() operation flips the image upside down (180° rotation). By averaging noise estimates for both orientations, we create an image that satisfies both prompts.

Part 1.9: Hybrid Images

Inspired by Project 2, we create hybrid images using diffusion models by combining low frequencies from one noise estimate with high frequencies from another.

Hybrid Image Algorithm

At each denoising step:

  1. $\epsilon_1 = \text{CFG of UNet}(x_t, t, p_1)$ - noise estimate for prompt 1
  2. $\epsilon_2 = \text{CFG of UNet}(x_t, t, p_2)$ - noise estimate for prompt 2
  3. $\epsilon = f_{\text{lowpass}}(\epsilon_1) + f_{\text{highpass}}(\epsilon_2)$ - combine frequencies
  4. Use $\epsilon$ for the denoising step

The low-pass filter extracts low frequencies (visible from far), and the high-pass filter extracts high frequencies (visible from near). The result looks like one image up close and another from far away.

Project 5B: Flow Matching from Scratch!

Part B Overview

In Part B, we build and train our own flow matching models from scratch on the MNIST dataset. Unlike Part A where we used pre-trained diffusion models, here we implement the complete training pipeline including the UNet architecture, the flow matching objective, and both unconditional and class-conditional generation. Flow matching is a continuous-time generative framework that learns to transport samples from a simple prior distribution (Gaussian noise) to the target data distribution through an ordinary differential equation (ODE).

The key insight of flow matching is that we define a time-dependent velocity field $v_\theta(x, t)$ that transforms noise $x_0 \sim \mathcal{N}(0, I)$ at time $t=0$ to data $x_1$ at time $t=1$. The model learns to predict this velocity field, enabling generation by integrating the ODE from $t=0$ to $t=1$.

Part 1: Training a Single-step Denoising UNet

Before diving into flow matching, we first train a simple denoising UNet that learns to remove Gaussian noise from images in a single step. This serves as a warm-up exercise to familiarize ourselves with the UNet architecture and training pipeline.

Part 1.1: Implementing the UNet

The UNet architecture consists of an encoder-decoder structure with skip connections. We implement several building blocks that are composed to form the full network.

Simple Operations

Each basic operation follows the pattern: Convolution → BatchNorm → GELU activation

  • Conv: 3×3 convolution with padding=1 (preserves spatial size)
  • DownConv: 3×3 convolution with stride=2 (halves spatial size)
  • UpConv: 4×4 transposed convolution with stride=2 (doubles spatial size)
  • Flatten: 7×7 average pooling followed by GELU
  • Unflatten: 7×7 transposed convolution followed by BatchNorm and GELU
Basic UNet Operations

Composed Operations

  • ConvBlock: Two sequential Conv operations
  • DownBlock: DownConv followed by ConvBlock
  • UpBlock: UpConv followed by ConvBlock

Unconditional UNet Architecture

The unconditional UNet takes a noisy 28×28 image and outputs a denoised image of the same size. The architecture consists of an encoder path that progressively downsamples the input, a bottleneck that compresses to a 1×1 spatial representation, and a decoder path that upsamples back to the original resolution. Skip connections concatenate encoder features to decoder features at matching resolutions.

Unconditional UNet Architecture

Architecture Details

Let $H$ = num_hiddens (we use $H = 128$):

  • Encoder:
    • ConvBlock: 1 → H channels (28×28)
    • DownBlock: H → H channels (14×14)
    • DownBlock: H → 2H channels (7×7)
  • Bottleneck:
    • Flatten: 2H channels (1×1)
    • Unflatten: 2H channels (7×7)
  • Decoder:
    • Concat + UpBlock: 4H → H channels (14×14)
    • Concat + UpBlock: 2H → H channels (28×28)
    • Concat + ConvBlock: 2H → H channels (28×28)
    • Conv2d: H → 1 channel (28×28)

As expected, this approach fails to generate meaningful images. The model learns to output the average of the training distribution (a blurry gray blob) because there's no correspondence between the random noise input and the target image. Different noise samples get mapped to unrelated images during training, so the model can only minimize the loss by outputting the mean. This is the same idea as centroid clustering, where to minimize the MSE, we simply want to average all of our datapoints, in this case the digits. This motivates the need for a structured approach like flow matching, where we establish a smooth path between noise and data.

Part 2: Flow Matching

Flow matching overcomes the limitations of one-step denoising by learning a time-dependent velocity field that gradually transforms noise into data. Instead of directly mapping noise to images, we interpolate between them and learn the velocity at each point along the path.

Flow Matching Framework

Define an interpolation path from noise $x_0 \sim \mathcal{N}(0, I)$ to data $x_1$:

$$x_t = t \cdot x_1 + (1-t) \cdot x_0$$

The target velocity at time $t$ is simply:

$$v^*(x_t, t) = x_1 - x_0$$

We train a neural network $v_\theta(x_t, t)$ to predict this velocity.

Part 2.1: Implementing a Time-Conditioned UNet

To implement flow matching, we need a UNet that takes both the image and a time parameter $t \in [0, 1]$ as input. The time conditioning is achieved by injecting the time embedding into the network via learned fully-connected blocks (FCBlocks).

FCBlock Architecture

The FCBlock processes the scalar time value through two linear layers:

Linear → GELU → Linear

This allows the network to learn a rich representation of time that can modulate the features at different stages of the UNet.

FCBlock Architecture

Time-Conditioned UNet Architecture

The time-conditioned UNet extends the unconditional UNet by adding time conditioning. Two FCBlocks project the scalar time $t$ to vectors that are multiplied element-wise with the features at the bottleneck and first upsampling stage.

Time-Conditioned UNet Architecture with FCBlocks for time injection

Time Conditioning Mechanism

Given time $t$, we compute two embeddings:

  • $t_1 = \text{FCBlock}_1(t)$ with output dimension $2H$
  • $t_2 = \text{FCBlock}_2(t)$ with output dimension $H$

These are applied via element-wise multiplication:

  • At bottleneck: $x \leftarrow t_1 \odot x$
  • After first up-block: $x \leftarrow t_2 \odot x$

Part 2.2: Training the Time-Conditioned UNet

Training Hyperparameters

  • Batch Size: 64
  • Learning Rate: 1e-2
  • Hidden Dimensions: 64
  • Number of Epochs: 10
  • Number of Timesteps (sampling): 50
  • Optimizer: Adam
  • Learning Rate Scheduler: ExponentialLR (γ = 0.1^(1/num_epochs))
Flow Matching Training Algorithm (Algorithm 1)

Training Objective

$$\mathcal{L} = \mathbb{E}_{x_1, x_0, t}\left[\|v_\theta(x_t, t) - (x_1 - x_0)\|^2\right]$$

where:

  • $x_1$ is a training image
  • $x_0 \sim \mathcal{N}(0, I)$ is sampled noise
  • $t \sim \text{Uniform}(0, 1)$ is a random timestep
  • $x_t = t \cdot x_1 + (1-t) \cdot x_0$ is the interpolated sample

Part 2.3: Sampling from the Time-Conditioned UNet

To generate new images, we start with pure Gaussian noise and integrate the learned velocity field from $t=0$ to $t=1$ using Euler integration.

Flow Matching Sampling Algorithm (Algorithm 2)

Euler Integration for Sampling

Starting from $x_0 \sim \mathcal{N}(0, I)$, iterate:

$$x_{t+\Delta t} = x_t + \Delta t \cdot v_\theta(x_t, t)$$

where $\Delta t = 1/T$ and $T$ is the number of timesteps (we use $T = 50$).

Part 2.4: Implementing a Class-Conditioned UNet

To enable conditional generation of specific digits, we extend the UNet to also condition on class labels. The class information is injected similarly to time, using additional FCBlocks.

Class-Conditioned UNet Architecture

Class and Time Conditioning

The class label $c \in \{0, ..., 9\}$ is converted to a one-hot vector $c_{\text{onehot}} \in \mathbb{R}^{10}$.

Similar to time, we compute class embeddings:

  • $c_1 = \text{FCBlock}_3(c_{\text{onehot}})$ with output dimension $2H$
  • $c_2 = \text{FCBlock}_4(c_{\text{onehot}})$ with output dimension $H$

The conditioning is now combined:

  • At bottleneck: $x \leftarrow c_1 \odot x + t_1$
  • After first up-block: $x \leftarrow c_2 \odot x + t_2$

Classifier-Free Guidance (CFG) Support

To enable classifier-free guidance during sampling, we train with random dropout of the class condition. A mask $m \sim \text{Bernoulli}(1 - p_{\text{uncond}})$ is sampled, and when $m = 0$, the class embeddings are zeroed out (unconditional generation).

Dropout probability (p_uncond): 0.1

Part 2.6: Sampling from the Class-Conditioned UNet

At inference time, we use Classifier-Free Guidance (CFG) to improve sample quality. CFG interpolates between unconditional and conditional predictions, pushing samples closer to the conditional distribution.

Class-Conditioned Sampling with CFG (Algorithm 4)

Classifier-Free Guidance

At each sampling step, we compute both conditional and unconditional velocities:

$$v_{\text{uncond}} = v_\theta(x_t, t, c, m=0)$$

$$v_{\text{cond}} = v_\theta(x_t, t, c, m=1)$$

The guided velocity is:

$$v_{\text{guided}} = v_{\text{uncond}} + \gamma (v_{\text{cond}} - v_{\text{uncond}})$$

where $\gamma$ is the guidance scale. We use $\gamma = 5.0$.

The comparison reveals interesting trade-offs:

  • ExponentialLR: Achieves the lowest final loss due to the decaying learning rate allowing fine-grained optimization in later epochs.
  • AdamW: Maintains a higher but more stable loss. The weight decay helps with regularization and the samples are of good quality.
  • No Scheduler: Shows higher variance in later epochs as the constant learning rate prevents fine convergence, but still produces reasonable samples.

All configurations produce recognizable digits, but the ExponentialLR scheduler provides the best balance of training stability and final sample quality by a very small margin. Interestingly, removing the learning rate scheduler does not seem to really redcue the quality of generated images by any noticeable amount. Even the AdamW images are reasonable except for one of the 9 digits which is not as sharp.

Conclusion

This project successfully demonstrated both the practical use of pre-trained diffusion models (Part A) and the implementation of flow matching from scratch (Part B):

Part A Achievements:

  • Implemented forward and reverse diffusion processes
  • Demonstrated iterative denoising and classifier-free guidance
  • Created image editing applications including SDEdit, inpainting, and text-conditional generation
  • Built optical illusions using visual anagrams and hybrid images

Part B Achievements:

  • UNet Architecture: Implemented a complete UNet with encoder-decoder structure and skip connections
  • Single-step Denoising: Trained a denoiser and explored its out-of-distribution behavior
  • Flow Matching: Implemented the continuous normalizing flow framework for generation
  • Time Conditioning: Extended the UNet with FCBlocks for time-aware generation
  • Class Conditioning: Enabled controlled generation of specific digits
  • Classifier-Free Guidance: Implemented CFG for improved sample quality
  • Optimizer Analysis: Compared different training configurations

The project reveals the elegant mathematical framework underlying modern generative models. Flow matching provides a clean, intuitive approach to learning generative models: define a path from noise to data, learn the velocity along that path, and integrate to generate. Combined with classifier-free guidance, this simple framework produces high-quality conditional samples, demonstrating the power and flexibility of flow-based generative models.
